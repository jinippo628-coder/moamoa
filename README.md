## v2.6
- 💣 폭탄 범위를 3×3 → **4×4**로 확대(1판당 1번).
- 폭탄도 블록처럼 **놓을 위치가 미리 표시**됩니다: 보드 위에서 손가락/마우스를 움직이면 4×4 범위가 주황색으로 빛나고, 손을 떼면 그 자리에서 펑!
  - 모바일 터치는 손가락이 목표 칸을 가리지 않도록 블록 드래그와 같은 감각으로 1.25칸 위를 조준합니다.
  - 보드 밖으로 빼면 프리뷰가 사라지고 발동되지 않으며, 빈 칸만 있으면 폭탄을 쓰지 않고 안내만 합니다.
  - 프리뷰와 실제 폭발은 같은 `getBombCells()`를 쓰므로 범위가 어긋나지 않습니다.
